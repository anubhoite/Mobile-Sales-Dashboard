# Mobile Sales Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze mobile phone sales performance and present sales insights through visualizations and key performance indicators (KPIs).

## Objectives
- Analyze mobile sales performance.
- Track important sales metrics and trends.
- Compare sales performance across available categories.
- Present data in an interactive dashboard to support business decision-making.

## Tools & Technologies
- **Power BI** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation, if used in the project
- **DAX** — KPI calculations, if used in the project

## Key Features
- Interactive sales dashboard
- KPI cards for important sales metrics
- Visual analysis of sales performance
- Filters and slicers, if included in the dashboard
- Visual representation of trends and comparisons

## Project File
The Power BI project file is available in this repository:

`mobile dashboard.pbix`

Download the file and open it using Microsoft Power BI Desktop to explore the dashboard.

## Skills Demonstrated
Data visualization, business intelligence reporting, dashboard design, analytical thinking, and data-driven decision-making.
